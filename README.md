# 👋 Привет! Всем!

Добро пожаловать в моё портфолио автоматизированного тестирования!  
Здесь собраны мои учебные и дипломные проекты по **автоматизации тестирования** с использованием **Python**, **Selenium**, **Pytest**, а также **API- и UI-тестов**.

---

## 🧪 Проекты

### 🍔 Stellar Burgers (Fast Food Service)
- **UI-автоматизация**: Тестирование веб-интерфейса заказа бургеров с использованием **Selenium + Pytest** и паттерна **Page Object**.  
- **API-тестирование**: Проверка корректности работы REST API сервиса.  
- **Юнит-тесты**: Валидация бизнес-логики приложения на уровне кода.  
> Часть дипломного проекта: три задания — UI, API и unit-тесты.

### 🛴 Яндекс.Самокат
- **UI-автоматизация**: Автотесты для фронтенда сервиса аренды самокатов с применением **Page Object**.  
- **API-тестирование**: Покрытие ключевых эндпоинтов сервиса.

### 📚 Books Collector
- **Юнит-тестирование**: Проверка логики приложения для сбора и управления коллекцией книг.

---

## 🛠️ Технологии и инструменты
- **Язык**: Python  
- **Фреймворки**: Pytest, Requests  
- **UI-тестирование**: Selenium WebDriver  
- **Паттерны**: Page Object Model (POM)  
- **API-тестирование**: REST, JSON  
- **CI/CD & Отчёты**: Allure
- **Системы контроля версий**: Git, GitHub
