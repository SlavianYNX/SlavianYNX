## Кейсы (коммерческий опыт, ООО «Акатосфера», с апреля 2026)

### Корпоративный мессенджер — Web SPA + Android
**306 автотестов** (pytest + Playwright + POM), из них **98 API**. Покрытие **101 из 169 требований (60%)**, P0 — **42 из 73**. API-регресс **157/157**.
Трассируемость через собственный маркер `pytest.mark.req` и выгрузку `rtm.json`. CI в GitHub Actions: ночной полный регресс, smoke на деплой, Allure-отчёты; мутационные проверки отделены маркером. Realtime-проверки через STOMP over WebSocket. Безопасность: IDOR, CSRF, XSS, идемпотентность отправки. **29 подтверждённых дефектов, 19 исправлены**, 3 закреплены регрессионными тестами в `xfail`.

### Сервис доставки — клиентское и курьерское приложения
UI-автотесты на Selenium WebDriver + POM (локаторы и данные вынесены в отдельные модули, обработка сетевых сбоев в фикстуре `driver`). API-автотесты на requests с **JWT-авторизацией двух ролей** и анонимным клиентом для негативных проверок. Сквозной сценарий **«Клиент → Курьер → Клиент»** с проверкой бизнес-правил: отмена только до взятия заказа, расчёт по адресам/типу/весу, отметки получения и оплаты.

### Telegram Mini App и цифровой семейный архив
Mini App: чек-лист **277 проверок по 18 модулям**, **131 тест-кейс** с трассировкой, планы тестирования и автоматизации.
Архив: QA-анализ MVP из **11 модулей**, проверки безопасности (HTTP→HTTPS и флаг Secure, CSRF, XSS, IDOR, подделка MIME, лимиты тарифов), **3 подтверждённых дефекта** и Python-скрипт воспроизведения с работой с CSRF-токеном и сессией.

### AI-IDE «Kodik» — стажировка, февраль–апрель 2026
