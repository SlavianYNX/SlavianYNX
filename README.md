## 🚀 Проекты

### 🍔 **Stellar Burgers** — Фастфуд-сервис *(Дипломный проект)*
> Комплексный проект, включающий три независимых задания:

| Тип тестирования | Технологии | Описание |
|------------------|-----------|----------|
| **Юнит-тесты** | `Python`, `pytest` | Проверка логики бэкенд-приложения для заказа бургеров |
| **API-тесты** | `Requests`, `pytest`, `JSON` | Валидация REST API: регистрация, авторизация, создание заказа |
| **UI-тесты** | `Selenium`, `pytest`, `Page Object` | Автоматизация сценариев на веб-интерфейсе: конструктор бургеров, личный кабинет |

---

### 🛴 **Яндекс.Самокат** — Сервис аренды самокатов
- 🧪 **UI-тесты**: Полноценная автоматизация ключевых пользовательских сценариев (выбор станции, оформление заказа) с использованием паттерна **Page Object**  
- 🔌 **API-тесты**: Покрытие эндпоинтов для проверки корректности бронирования и статусов самокатов  

---

### 📚 **Books Collector** — Учёт книг
- 🔍 **Юнит-тесты**: Проверка бизнес-логики: добавление книг, формирование избранного, ограничения по возрасту  
- 🧱 Простой, но эффективный пример тестирования без UI и внешних зависимостей
