## Подход к работе

- Покрытие считается по матрице трассируемости, а не «на глаз».
- Известный дефект — `xfail` с описанием, а не подогнанный под фактическое поведение ассерт.
- Ассерты на инварианты и согласованность данных, а не на константы, которые завтра поменяются.
- Секреты — только в secrets CI: креды и адреса стендов не попадают в репозиторий и артефакты отчётов.
